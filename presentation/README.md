# ACTOR / Система в действии

Интерактивная презентация на русском. 12 слайдов, около 8 минут.

Публичная ссылка: <http://5.181.134.236/presentation/>. Исходники находятся в `presentation/` репозитория Actor.

## Открыть

Открой `index.html` в Safari или Chrome. Все шрифты, схемы и изображения лежат рядом. Интернет и установка пакетов не нужны.

Для локального HTTP-предпросмотра из `presentation/`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Адрес: <http://127.0.0.1:4173/>. Остановить сервер: `Ctrl+C`.

## Управление

| Действие | Клавиша |
| --- | --- |
| Следующий / предыдущий слайд | `→` / `←` |
| Следующий / предыдущий слайд | `PageDown` / `PageUp` |
| Следующий / предыдущий слайд | `Пробел` / `Shift+Пробел` |
| Первый / последний слайд | `Home` / `End` |
| Содержание | `O` или `Щ` |
| Заметки докладчика | `N` или `Т` |
| Полный экран | `F` или `А` |
| Закрыть окно | `Esc` |

Есть кнопки со стрелками, прямая ссылка на слайд `#1` — `#12` и горизонтальный свайп на телефоне. На узких экранах длинный слайд можно прокрутить. На слайдах работают переключатели и схемы. Системная настройка уменьшения движения отключает анимации.

## Файлы

- `index.html` — содержание и структура слайдов.
- `style.css` — цвет, шрифты, сетка, анимации, адаптация и печатный стиль.
- `app.js` — навигация, взаимодействия, заметки докладчика и ссылки.
- `station-data.js` — копия публичной геометрии станции.
- `assets/` — локальные шрифты, векторные персонажи и настоящий снимок игры.
- `research/` — архитектурное исследование, источники, опись репозитория и условия проверки.
- `CREDITS.md` — происхождение материалов и лицензии шрифтов.

## Обновление

Меняй короткий текст слайда в `index.html`, подробный рассказ — в `speakerNotes` внутри `app.js`. В конце `style.css` лежат правила для разных размеров экрана. После изменений перезагрузи страницу.
