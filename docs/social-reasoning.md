# Social reasoning and bounded cognition

Arena's installed match policy explains game mechanics and strategic options for both sides in the same role-neutral Objective. A player learns its actual side, duty, life, timers and public phase only from its own permitted observations. The policy chooses no victim, ballot, alibi or winner. It does not supply a hidden role seed, remote actor position or a scripted decision to a real Brain.

`WorkingKnowledge` retains four distinct kinds: `historical_observation`, `player_claim`, `hypothesis`, and `contradiction`. Every record has a match scope, source event/actor, observed time, expiry, sequence/revision and explicit retention policy. A visible actor's disappearance removes it from current state; the last delivered position remains dated history. Received text always keeps its author and unverified-claim status. There is no chat-keyword guilt detector or automatic alignment inference. An Impostor may deliberately send a false alibi or witness story as a game action; internally it remains a claim, with no invented observed event or evidence reference.

The model may choose `actor.remember-hypothesis` or `actor.remember-contradiction` to retain a concise uncertain statement with evidence IDs. A contradiction requires two distinct existing sources and remains `unresolved_incompatibility`; ACTOR does not declare a liar. Missing/foreign evidence is rejected. Citing a personally available fact freezes its exact source/event/sequence/time/content under a bounded evidence-snapshot ID; a later update to a latest-value record cannot rewrite that citation. Notes cannot outlive the earliest cited source, and bounded context selection never intentionally leaves a note without its retained dependencies. These are short game beliefs, not stored private model reasoning.

During Discussion, `agents-arena.discuss` sends the model's chosen argument/question/defence/misleading game claim through the ordinary Standard Communication command, waits for real server acceptance, then gathers a short burst of replies. `agents-arena.await-discussion-update` gathers unread early/new discussion messages without sending. Both return authors, server sequences/times and expiry, with text explicitly marked as a player claim. A configurable short settle window batches messages into one Skill result, and a decision reserve stops waiting before the phase deadline. Ordinary chat does not force a replan or call Codex. Critical authoritative phase/life events can still cancel stale work immediately. A delivery receipt never proves another Brain read or believed a message.

`agents-arena.follow-visible-actor` lets the model select a currently visible player and a bounded following duration. Local steering uses only current permitted peers, the public authored floor envelope and fresh own physics. A tiny velocity lead is limited to current sight. Losing visibility removes that lead: only the fixed last delivered point can be approached for at most three configured seconds, then movement stops. It never attacks or identifies a side. A current opportunity still requires the Brain to select a separate server-validated action. `approach-visible-actor` uses the same controller and requires four distinct stopped observations inside the public configured range. Own phase, life and authenticated connection generation invalidate movement; no teleport or collider bypass is used.

Task Skills perform the same visible mechanics as Human play: continuous maintenance, displayed timed circuit choices, or a two-sample sensor trend. The Skill interprets only its own targeted work prompt, sends typed step commands and awaits receipts; it does not call a model for each mechanical step. Work acceptance and step acknowledgements are separate from final original-request completion. Cancellation names only that Skill's own work ID/start correlation. Resume generation fences old commands even when the match phase did not change; new cognition waits for a coherent own-state observation.

Cost reduction is bounded and observable: phase-specific raw capability selection avoids sending irrelevant motor/task panels, working knowledge is capped by entries and bytes, and the Codex adapter deduplicates identical trusted catalog schemas. Exploration retains the actual own Transform for spatial decisions; Arena guidance distinguishes its root position from visible physical centres. Its original structured output schema and Runtime/Skill validation remain unchanged. Reports expose actual context bytes, catalog source/trusted bytes, unique schema counts, provider duration and measured SDK usage. Byte/token heuristics are not measured provider cost, and fewer snapshot bytes do not prove a particular saving on a real model run.

During participation, closed episode reports and private activity identifiers stay withheld. A bounded internal ledger retains only the registered decision/result Skill IDs at their exact report positions. After the installed policy observes an authoritative terminal boundary, the controller can restore those IDs in a copy of the already-redacted episode reports. Private arguments, output, messages and context are never restored. Earlier live snapshots remain unchanged; a failed nonterminal participation discards the ledger, and a new controller starts empty. Older artifacts without this metadata cannot recover action identity from generic counters.

Offline regressions cover evidence expiry/grouping, claim privacy, no chat replan, early reply batching, real correlated message/task receipts, generation races, current/last-seen pursuit and actuator cleanup. They contain no model calls or Unity clients. Live multi-model social interaction, deception quality, rendered gameplay and token/time comparisons remain separate integration acceptance checks.
