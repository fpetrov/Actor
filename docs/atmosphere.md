# Station atmosphere

The SocialDeduction client has a quiet orbital backdrop, a softly moving blue-grey visibility veil and ten small deck lamps. The existing Atmospheric art remains the source for floors, hull, consoles and characters. The effect attaches through `AtmosphericPresentationHost`; it does not require rebuilding the saved map or modifying gameplay geometry.

## Visibility boundary

`SocialFogRenderer` retains the same 192 rays / 193 current-eye queries, Human opening envelope, instantaneous closing, Broadcast refresh schedule, epoch reset and `MatchesPresentedSight` gate. The original outer annulus vertices B/C remain alpha 1 at sorting order 2000. `StationFog.shader` keeps that alpha 1 exact. It samples only the original public space texture and a small analytic color field; it never samples the camera color, depth, actor state or an old sight polygon.

The wider default feather is 12 screen pixels, bounded to 16. It is added **inside** the current permitted polygon. The animated ripple changes only its inward shading and the opaque fog RGB. The outside region is opaque navy/grey space with a very subdued silhouette sampled from the existing **immutable station-floor PNG**. It gives the impression of a translucent veil without showing the live scene behind it. The material's Public Floor Silhouette setting can disable this authored layer. It contains no wall landmarks, terminals, lights, names, actors, bodies, activity or changing map state. Hidden dynamic content therefore cannot become visible through a cosmetic opacity reduction. The four existing `StaticSurfaceArt` landmarks keep their separate front/range/LOS gates and exact reactor exemption unchanged.

## Lighting and public emergency

`StationAtmosphere2D` creates one backdrop quad and ten fixed, authored light-pool quads. They use shared resources and one shared mesh, with no shadow textures, post-processing, particles, per-frame object scans or new sight queries. The fog uses two texture samples (the new backdrop plus the already-loaded static floor), the background uses one and the bounded local pools use no texture samples. The pools draw below actors and below the fog. The palette shaders receive a shared ambient tint, while small warm emitters give rooms a common visual vocabulary.

The current game has a **life-support emergency**, not a separate electrical-blackout game rule. Its existing public `Emergency.Active` signal smoothly dims the ordinary palette and changes the local emitters to subdued red/amber emergency lights. Repair restores the working palette. This is a visual emergency response; it does not change authoritative visibility radius, navigation or actions. Broadcast uses the current `Applied` public camera frame behind the existing `PresentationSight` freshness gate, matching expected connection identity and sight epoch. The ordinary client uses the current local player endpoint, requiring its own valid state and the same emergency/match identity. No roles, private tasks or other players' own observations are read. Lost presentation clears the emergency envelope immediately; match, connection generation, view epoch and audience changes install their own current public signal immediately, without blending an old signal or causing a bright camera-switch flash during an ongoing emergency. GameOver restores ordinary lighting.

The existing Reduced motion setting freezes the current cosmetic drift and beacon phase; it leaves visibility and emergency state responsive. The beacon is a slow, low-amplitude breathing light rather than a hard strobe.

## Original backdrop asset

Built-in `image_gen` mode created `Agents Arena/Assets/Art/Atmospheric/Backdrop/station-orbit-v1.png`. The original opaque 1672×941 PNG is 2061759 bytes; SHA256 is `9fe3908b9e296e375aa3852c841901c2519e20d347e411c23148a48952511954`. Unity imports it as a non-readable, bilinear, clamped, sRGB default texture with maximum dimension 1024 and high-quality platform-selected compression. Both fog and background use the same world mapping, so the image is public scenery rather than information about hidden rooms. The PNG is stored in the repository, not referenced from an external generation folder.

Generation prompt:

> Use case: stylized-concept. Asset type: original background texture for an orthographic 2D top-down social deduction game set on a small orbital research station. Paint a quiet deep-space backdrop to replace empty black behind the whole station map. Restrained hand-painted game art matching soft desaturated sage, warm cream metal and charcoal-blue station sprites. Sparse tiny distant stars, very faint broad blue-grey nebula wisps with a little desaturated teal, soft dusty gradients, subdued low contrast; clearly space rather than smoke filling a room. Wide landscape, distributed uniformly, no central focal object. Dark navy and blue-grey rather than absolute black, stars only occasional pinpoints. Keep quiet areas so the bright station silhouette and players remain primary. Opaque image. Original asset; no ships, station, planets, characters, objects, UI, labels, text, logos, border, lens flare, bright galaxies or large colorful clouds. Not a screenshot; no copied assets from other games.

The reference direction is restrained environmental depth and readable visibility boundaries, not copied Dota art. Valve's [Reborn tools overview](https://www.dota2.com/reborn/part2) describes lighting as part of assessing a map in its editor. Unity's [URP 2D light documentation](https://docs.unity.com/en-us/engine/6000.3/manual/unity2d/2d-urp/2d-index/2d-light-properties-explained) explains that compatible shaders are required and that additional light/sorting-layer combinations can increase light/shadow texture work. This implementation keeps the existing unlit art pipeline and uses bounded cosmetic pools instead of introducing a new light-render-texture pipeline.

## Verification

Pure `StationAtmosphereTests` cover bounded screen-space feather dimensions, same-match emergency fencing, rematch/reconnect/view-epoch/audience changes, immediate removal of stale emergency state, smooth transition/restoration and non-finite/timing guards. Existing Broadcast presentation, static-surface and fog rules are also part of the targeted regression subset. These tests do not prove rendered appearance or GPU cost.

`SocialPresentationVerification.ValidateProductionShaders` now includes StationFog, StationBackdrop and StationGlow. The separate `Actor.Editor.SocialPresentationVerification.VerifyStationFogSeal` entrypoint requires a real Editor graphics device and the actual URP 2D renderer. It creates only an owned temporary scene, renders red then green synthetic geometry behind an alpha 1 production-fog quad, and checks that covered pixels remain identical while uncovered pixels change. It separately checks cosmetic RGB drift and a frozen-clock repeat. It writes `build/atmosphere-validation/fog-seal.json` and `fog-seal.png`, restores globals and closes only its own scene. A Null renderer or missing/unsupported/error shader cannot pass.

Actual windowed Human/Broadcast checks, emergency/repair footage, epoch/stale transitions and before/after frame/GPU timings remain required after integration. No native gameplay, visual-quality acceptance or performance numbers are claimed by source tests. Keep the original 192-ray privacy budget and compare the same window size, sight path and capture load. Headless/server builds omit the presentation component implementation.
